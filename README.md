# CodeFlow

A command line program that walks you through a daily study structure. 
It runs a stopwatch to track your total time working, and moves through 
the day as a state machine of primers (a few interactive prompts to gently 
load project context back into your brain), work sessions, and breaks. 
Basically, the program forces me to chunk tasks constantly. I'm building 
this to give my ADHD brain a structure of small, concrete tasks to follow 
each day as I work. The hardest part for me is always starting up, which 
this program tries to make easier by keeping me organized.

Built in TypeScript on Node.

## Status

Early development. Built one commit at a time as a TypeScript learning project.
